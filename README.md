# ระบบติดตามมติที่ประชุม

เว็บแอปสำหรับติดตามมติจากการประชุม และร่างอีเมลติดตามงานถึงผู้รับผิดชอบ
เปิดใน Google Chrome ได้ทันที ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องติดตั้งโปรแกรม และใช้ได้แม้ไม่มีอินเทอร์เน็ต

---

## เริ่มใช้งาน

1. ดับเบิลคลิก `index.html` หรือคลิกขวา → Open with → **Google Chrome**
2. ครั้งแรก กด **"ตั้งค่าผู้ส่งอีเมล"** แล้วกรอกชื่อ ตำแหน่ง หน่วยงาน (ใช้ลงท้ายอีเมลทุกฉบับ)
3. กด **"+ เพิ่มรายการ"** เพื่อบันทึกมติแรก

> แนะนำ: ปักหมุดหน้านี้ไว้ใน Chrome (กด Ctrl+D) จะได้เปิดได้เร็ว

---

## การใช้งานประจำวัน

### เพิ่ม / แก้ไข / ลบรายการ

- **เพิ่ม:** กด "+ เพิ่มรายการ" กรอกข้อมูล แล้วกด "บันทึก" (ช่องที่มี * ต้องกรอก)
- **ผู้รับผิดชอบหลายคน / หลายอีเมล:** คั่นด้วยจุลภาค เช่น `คุณ ก, คุณ ข`
- **แก้ไข:** กด "แก้ไข" ท้ายแถว (เช่น เปลี่ยนสถานะเป็น "เสร็จแล้ว")
- **ลบ:** กด "ลบ" ระบบจะถามยืนยันก่อน ลบแล้วกู้คืนไม่ได้ (ยกเว้นนำเข้าจากไฟล์สำรอง)
- ข้อมูลบันทึกอัตโนมัติทันที ไม่ต้องกดบันทึกไฟล์

### ดูและกรองรายการ

- **ตัวเลขสรุป** มุมขวาบน (ทั้งหมด / ยังไม่เสร็จ / เลยกำหนด) กดเพื่อกรองได้ทันที
- **กรองตามสถานะ:** "ยังไม่เสร็จ" = ทุกรายการที่ยังค้าง, "เลยกำหนด" = เฉพาะที่เกินเวลา
- **กรองตามผู้รับผิดชอบ:** รายชื่อดึงจากข้อมูลอัตโนมัติ รายการที่มีหลายคนจะขึ้นเมื่อเลือกคนใดคนหนึ่ง
- **ค้นหา:** พิมพ์คำในชื่อการประชุม มติ ผู้รับผิดชอบ อีเมล หรือหมายเหตุ
- **เรียงลำดับ:** กดหัวคอลัมน์ (กดซ้ำเพื่อสลับ น้อย→มาก / มาก→น้อย)
- **แถวสีแดง** = เลยกำหนดเสร็จและยังไม่เสร็จ (ใต้วันที่บอกว่าเลยมากี่วัน)
- **ข้อความสีส้ม** ใต้วันที่ = ครบกำหนดวันนี้ หรือภายใน 7 วัน

### ร่างอีเมลติดตามมติ

1. กด **"ร่างอีเมล"** ท้ายแถวของมติที่ต้องการ
2. แก้ข้อความได้ตามต้องการ แล้วกดปุ่มคัดลอกทีละช่อง ไปวางในโปรแกรมอีเมล (Outlook / Gmail)
   - **คัดลอกอีเมลผู้รับ** — ผู้รับทุกคน คั่นด้วย `;`
   - **คัดลอกหัวเรื่อง**
   - **คัดลอกเนื้อหา**
3. ส่งอีเมลจากโปรแกรมอีเมลของคุณ แล้วกลับมากด **"บันทึกว่าส่งแล้ว"**
   (เปลี่ยนวันที่ได้ ถ้าส่งไปก่อนหน้านี้)

หมายเหตุ
- ถ้ารายการเลยกำหนดแล้ว ร่างจะใช้ข้อความแบบติดตามงานที่เลยกำหนดให้อัตโนมัติ
- ข้อความที่แก้ในร่างไม่ถูกเก็บไว้ ปิดแล้วเปิดใหม่จะได้ร่างเริ่มต้น (กด "สร้างร่างใหม่" เพื่อเริ่มใหม่ได้)
- ในตารางจะแสดง "ส่งอีเมลล่าสุด" ใต้สถานะ ดูประวัติทั้งหมด และลบวันที่ที่บันทึกผิดได้ในหน้าร่างอีเมล

## ⚠️ ข้อมูลเก็บที่ไหน และวิธีสำรองข้อมูล

ข้อมูลเก็บไว้ **ใน Chrome ของเครื่องนี้** ไม่ได้อยู่ในไฟล์ในโฟลเดอร์
OneDrive จึง **ไม่ได้** สำรองข้อมูลให้ — ต้องสำรองเองด้วยปุ่ม "ส่งออก Excel"

| สถานการณ์ | ข้อมูลยังอยู่ไหม |
|---|---|
| ปิด Chrome / ปิดเครื่อง แล้วเปิดใหม่ | ✅ อยู่ |
| ย้ายหรือเปลี่ยนชื่อโฟลเดอร์โปรแกรม (เปิดด้วย Chrome เครื่องเดิม) | ✅ อยู่ |
| ล้างข้อมูลการท่องเว็บ (Clear browsing data) ที่เลือก "คุกกี้และข้อมูลเว็บไซต์" | ❌ หาย |
| เปิดด้วย browser อื่น (Edge, Firefox) หรือ Chrome โปรไฟล์อื่น | ❌ ไม่เห็นข้อมูล |
| เปิดจากคอมพิวเตอร์เครื่องอื่น (แม้จะซิงก์โฟลเดอร์ผ่าน OneDrive) | ❌ ไม่เห็นข้อมูล |

ทุกกรณีที่ ❌ กู้คืนได้ด้วย **"นำเข้า Excel"** จากไฟล์ที่สำรองไว้

### กิจวัตรที่แนะนำ

- กด **"ส่งออก Excel"** อย่างน้อยสัปดาห์ละครั้ง (หรือหลังแก้ข้อมูลเยอะ ๆ)
- ย้ายไฟล์จากโฟลเดอร์ Downloads ไปเก็บในโฟลเดอร์ OneDrive เช่น `meeting-tracker/สำรองข้อมูล/`
- ใต้ปุ่มด้านบนจะบอกว่า **สำรองข้อมูลล่าสุดเมื่อไร** และขึ้นแถบสีส้มเมื่อมีข้อมูลที่ยังไม่ได้สำรอง

> ถ้าอยากให้ Chrome ถามที่บันทึกไฟล์ทุกครั้ง (เลือกโฟลเดอร์ OneDrive ได้ตรง ๆ):
> Chrome → การตั้งค่า → การดาวน์โหลด → เปิด "ถามตำแหน่งที่จะบันทึกไฟล์แต่ละไฟล์ก่อนดาวน์โหลด"

### ย้ายไปใช้เครื่องใหม่

1. เครื่องเดิม: กด "ส่งออก Excel"
2. เครื่องใหม่: เปิด `index.html` ด้วย Chrome → กด "นำเข้า Excel" → เลือกไฟล์นั้น

## ส่งออก / นำเข้า Excel

- **ส่งออก Excel:** ได้ไฟล์ `มติประชุม_2569-11-10.xlsx` (วันที่ในชื่อไฟล์เป็น พ.ศ.) มี 2 แผ่นงาน
  - "มติประชุม" — ข้อมูลทั้งหมด วันที่เป็นเซลล์วันที่ของ Excel (แสดงแบบ วว/ดด/ปปปป ค.ศ.)
  - "ตั้งค่าผู้ส่ง" — ชื่อ ตำแหน่ง หน่วยงานผู้ส่ง
- **นำเข้า Excel:** เลือกไฟล์ → ระบบตรวจข้อมูลทุกแถวก่อน
  - ถ้าพบปัญหา จะบอกเลขแถวและสาเหตุ และ **ไม่เปลี่ยนข้อมูลเดิม**
  - ถ้าไฟล์ถูกต้อง จะถามยืนยัน แล้ว **ดาวน์โหลดไฟล์สำรองข้อมูลปัจจุบันอัตโนมัติ**
    (`สำรองก่อนนำเข้า_2569-11-10_0930.xlsx`) ก่อนแทนที่ข้อมูล **ทั้งหมด** ด้วยข้อมูลจากไฟล์

### ถ้าจะแก้ข้อมูลในไฟล์ Excel แล้วนำเข้ากลับ

- ห้ามแก้ชื่อหัวตารางในแถวแรก (เพิ่มคอลัมน์อื่นเองได้ ระบบจะไม่สนใจ)
- วันที่: ใช้เซลล์วันที่ของ Excel หรือพิมพ์ `วว/ดด/ปปปป` ได้ทั้ง ค.ศ. และ พ.ศ. (เช่น `15/11/2569`)
- สถานะ: ใช้ได้เฉพาะ `ยังไม่เริ่ม` / `กำลังดำเนินการ` / `เสร็จแล้ว`
- ครั้งที่: ถ้าพิมพ์ `5/2569` แล้ว Excel เปลี่ยนเป็นวันที่ ให้พิมพ์ `'5/2569` (มี ' นำหน้า)
- แถวใหม่ไม่ต้องใส่ "รหัส" ระบบสร้างให้เอง
- หลายคน / หลายอีเมล คั่นด้วยจุลภาค ( , ) หรือ ;
- มติหลายบรรทัดอาจแสดงเป็นบรรทัดเดียวใน Excel — เลือกคอลัมน์แล้วกด "ตัดข้อความ" (Wrap Text)

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| บรรทัดล่างสุดขึ้นสีแดง "โหลดไลบรารี Excel ไม่สำเร็จ" | ตรวจว่ามีไฟล์ `lib/xlsx.full.min.js` อยู่ (OneDrive อาจยังดาวน์โหลดไม่เสร็จ — คลิกขวาโฟลเดอร์ → "เก็บไว้ในอุปกรณ์นี้เสมอ") |
| เปิดแล้วตารางว่าง ทั้งที่เคยกรอกไว้ | ตรวจว่าเปิดด้วย Chrome โปรไฟล์เดิม ถ้าใช่และข้อมูลหาย ให้ "นำเข้า Excel" จากไฟล์สำรองล่าสุด |
| ขึ้นข้อความ "ข้อมูลที่บันทึกไว้อ่านไม่ได้" | นำเข้าจากไฟล์ Excel ที่สำรองไว้ (ระบบเก็บสำเนาข้อมูลเสียไว้แล้ว ไม่ได้ลบทิ้ง) |
| กดคัดลอกแล้วขึ้น "คัดลอกไม่สำเร็จ" | คลิกในช่องข้อความ กด Ctrl+A แล้ว Ctrl+C เพื่อคัดลอกเอง |
| วางอีเมลผู้รับใน Outlook แล้วไม่แยกคน | ตรวจว่าคั่นด้วย `;` (ระบบใส่ให้แล้ว) หรือวางทีละอีเมล |
| นำเข้าไม่ได้ ขึ้นรายการข้อผิดพลาด | แก้ตามเลขแถวที่แจ้งในไฟล์ Excel แล้วนำเข้าใหม่ |

## ข้อจำกัด

- ใช้ได้ทีละคน บนเครื่องเดียว (ไม่ได้ซิงก์ข้อมูลระหว่างเครื่องหรือระหว่างคน)
- ไม่ส่งอีเมลเอง — คัดลอกไปวางในโปรแกรมอีเมล
- ช่องเลือกวันที่ในฟอร์มแสดงตามภาษาของ Chrome (อาจเป็น ค.ศ.) แต่ในตารางและอีเมลแสดงเป็น พ.ศ. เสมอ
- ไฟล์ HTML อื่นที่เปิดจากเครื่องด้วย Chrome ใช้พื้นที่เก็บข้อมูลเดียวกัน (ระบบใช้ชื่อเฉพาะ `meetingTracker.*` จึงไม่ปนกัน)

## สำหรับผู้ดูแลระบบ

### โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอ ฟอร์ม และหน้าต่างต่าง ๆ |
| `style.css` | หน้าตาและสี |
| `app.js` | โค้ดการทำงานทั้งหมด (แบ่งเป็นหมวดตามหัวข้อในไฟล์) |
| `lib/xlsx.full.min.js` | ไลบรารีอ่าน/เขียน Excel ([SheetJS](https://sheetjs.com) รุ่น 0.20.3 ดาวน์โหลดจาก cdn.sheetjs.com) |

### ข้อมูลใน Chrome (localStorage)

| ชื่อ | เก็บอะไร |
|---|---|
| `meetingTracker.items` | รายการมติทั้งหมด (JSON) วันที่เก็บเป็น `ปปปป-ดด-วว` แบบ ค.ศ. |
| `meetingTracker.settings` | ข้อมูลผู้ส่งอีเมล |
| `meetingTracker.lastExport` | เวลาที่สำรองเป็น Excel ล่าสุด |
| `meetingTracker.lastChange` | เวลาที่แก้ข้อมูลล่าสุด |

### จุดที่แก้บ่อย

- **ถ้อยคำในร่างอีเมล:** ฟังก์ชัน `buildDraft` ใน `app.js`
- **จำนวนวันที่ถือว่า "ใกล้ครบกำหนด" (ตอนนี้ 7 วัน):** ฟังก์ชัน `dueNote` ใน `app.js`
- **สี:** ตัวแปรใน `:root` ด้านบนของ `style.css`

### git

ประวัติการแก้ไขเก็บด้วย git ในโฟลเดอร์นี้ ไฟล์ `.xlsx` / `.csv` ไม่ถูกเก็บใน git
(ตั้งไว้ใน `.gitignore`) เพราะมีชื่อและอีเมลบุคคล
