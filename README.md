# ระบบติดตามมติที่ประชุม

เว็บแอปสำหรับติดตามมติจากการประชุม เปิดใช้ใน browser ได้ทันที ไม่ต้องมีเซิร์ฟเวอร์ และไม่ต้องติดตั้งโปรแกรมเพิ่ม

## วิธีเปิดใช้

ดับเบิลคลิกไฟล์ `index.html` (แนะนำให้เปิดด้วย Google Chrome)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอ |
| `style.css` | หน้าตาและสี |
| `app.js` | โค้ดการทำงาน |
| `lib/xlsx.full.min.js` | ไลบรารีอ่าน/เขียน Excel ([SheetJS](https://sheetjs.com) รุ่น 0.20.3) |

## ข้อมูลเก็บที่ไหน

ข้อมูลเก็บใน browser (localStorage) ของเครื่องที่ใช้งาน **ไม่ได้อยู่ในไฟล์**
OneDrive จึงไม่ได้สำรองข้อมูลให้ — ควรกด "ส่งออก Excel" เป็นประจำ (เช่น สัปดาห์ละครั้ง)
แล้วย้ายไฟล์จากโฟลเดอร์ Downloads ไปเก็บใน OneDrive

ข้อมูลจะหายถ้า: ล้างข้อมูลการท่องเว็บ (Clear browsing data) ของ Chrome,
เปลี่ยนเครื่อง/เปลี่ยน browser, หรือย้ายโฟลเดอร์โปรแกรมไปที่อื่น
— ทุกกรณีกู้คืนได้ด้วย "นำเข้า Excel" จากไฟล์ที่สำรองไว้

## เพิ่ม / แก้ไข / ลบรายการ

- **เพิ่ม:** กด "+ เพิ่มรายการ" กรอกข้อมูล แล้วกด "บันทึก" (ช่องที่มี * ต้องกรอก)
- **ผู้รับผิดชอบหลายคน / หลายอีเมล:** คั่นด้วยจุลภาค เช่น `คุณ ก, คุณ ข`
- **แก้ไข:** กดปุ่ม "แก้ไข" ท้ายแถว
- **ลบ:** กดปุ่ม "ลบ" ระบบจะถามยืนยันก่อน ลบแล้วกู้คืนไม่ได้
- ข้อมูลบันทึกอัตโนมัติทันทีที่กด "บันทึก" หรือยืนยันการลบ

## ดูและกรองรายการ

- **ตัวเลขสรุป** มุมขวาบน (ทั้งหมด / ยังไม่เสร็จ / เลยกำหนด) กดเพื่อกรองได้ทันที
- **กรองตามสถานะ:** เลือก "ยังไม่เสร็จ" เพื่อดูทุกรายการที่ยังค้าง หรือ "เลยกำหนด" เพื่อดูเฉพาะที่เกินเวลา
- **กรองตามผู้รับผิดชอบ:** รายชื่อดึงจากข้อมูลอัตโนมัติ รายการที่มีหลายคนจะขึ้นเมื่อเลือกคนใดคนหนึ่ง
- **ค้นหา:** พิมพ์คำในชื่อการประชุม มติ ผู้รับผิดชอบ อีเมล หรือหมายเหตุ
- **เรียงลำดับ:** กดหัวคอลัมน์ (กดซ้ำเพื่อสลับ น้อย→มาก / มาก→น้อย)
- **สีแดง** = เลยกำหนดเสร็จและยังไม่เสร็จ ใต้วันที่จะบอกว่าเลยมากี่วัน
  ส่วนรายการที่ใกล้ครบกำหนด (ภายใน 7 วัน) จะมีข้อความสีส้มบอกจำนวนวันที่เหลือ

## ร่างอีเมลติดตามมติ

1. ครั้งแรก กด **"ตั้งค่าผู้ส่งอีเมล"** กรอกชื่อ ตำแหน่ง หน่วยงาน (ใช้ลงท้ายอีเมลทุกฉบับ)
2. กด **"ร่างอีเมล"** ท้ายแถวของมติที่ต้องการ
3. แก้ข้อความได้ตามต้องการ แล้วกดปุ่มคัดลอกทีละช่อง ไปวางในโปรแกรมอีเมล (Outlook / Gmail)
   - **คัดลอกอีเมลผู้รับ** — ผู้รับทุกคน คั่นด้วย `;`
   - **คัดลอกหัวเรื่อง**
   - **คัดลอกเนื้อหา**
4. ส่งอีเมลจากโปรแกรมอีเมลของคุณ แล้วกลับมากด **"บันทึกว่าส่งแล้ว"**
   (เปลี่ยนวันที่ได้ ถ้าส่งไปก่อนหน้านี้)

หมายเหตุ
- ถ้ารายการเลยกำหนดแล้ว ร่างจะใช้ข้อความแบบติดตามงานที่เลยกำหนดให้อัตโนมัติ
- ข้อความที่แก้ในร่างไม่ถูกเก็บไว้ ปิดแล้วเปิดใหม่จะได้ร่างเริ่มต้น
- ในตารางจะแสดง "ส่งอีเมลล่าสุด" ใต้สถานะ ดูประวัติทั้งหมดและลบวันที่ที่บันทึกผิดได้ในหน้าร่างอีเมล

## สำรองและนำเข้าข้อมูล (Excel)

- **ส่งออก Excel:** ได้ไฟล์ `มติประชุม_2569-11-10.xlsx` (วันที่เป็น พ.ศ.) ในโฟลเดอร์ Downloads
  มี 2 แผ่นงาน: "มติประชุม" (ข้อมูลทั้งหมด) และ "ตั้งค่าผู้ส่ง"
- ใต้ปุ่มด้านบนจะบอกว่า **สำรองข้อมูลล่าสุดเมื่อไร** และเตือนสีส้มถ้ามีการแก้ไขหลังจากนั้น
- **นำเข้า Excel:** เลือกไฟล์ → ระบบตรวจข้อมูลทุกแถวก่อน
  - ถ้าพบปัญหา จะบอกเลขแถวและสาเหตุ และ **ไม่เปลี่ยนข้อมูลเดิม**
  - ถ้าไฟล์ถูกต้อง จะถามยืนยัน แล้ว **ดาวน์โหลดไฟล์สำรองข้อมูลปัจจุบันอัตโนมัติ**
    (`สำรองก่อนนำเข้า_2569-11-10_0930.xlsx`) ก่อนแทนที่ข้อมูลทั้งหมดด้วยข้อมูลจากไฟล์

### ถ้าจะแก้ข้อมูลในไฟล์ Excel แล้วนำเข้ากลับ

- ห้ามแก้ชื่อหัวตารางในแถวแรก (เพิ่มคอลัมน์อื่นเองได้ ระบบจะไม่สนใจ)
- วันที่: ใช้เซลล์วันที่ของ Excel หรือพิมพ์ `วว/ดด/ปปปป` ได้ทั้ง ค.ศ. และ พ.ศ. (เช่น `15/11/2569`)
- สถานะ: ใช้ได้เฉพาะ `ยังไม่เริ่ม` / `กำลังดำเนินการ` / `เสร็จแล้ว`
- ครั้งที่: ถ้าพิมพ์ `5/2569` แล้ว Excel เปลี่ยนเป็นวันที่ ให้พิมพ์ `'5/2569` (มี ' นำหน้า)
- แถวใหม่ไม่ต้องใส่ "รหัส" ระบบสร้างให้เอง
- หลายคน / หลายอีเมล คั่นด้วยจุลภาค ( , ) หรือ ;

> คู่มือส่วนอื่นจะเพิ่มเมื่อทำแต่ละขั้นเสร็จ
