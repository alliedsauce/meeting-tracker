# ระบบติดตามมติที่ประชุม

เว็บแอปสำหรับติดตามมติจากการประชุม เปิดใช้ใน browser ได้ทันที ไม่ต้องมีเซิร์ฟเวอร์ และไม่ต้องติดตั้งโปรแกรมเพิ่ม

## วิธีเปิดใช้

ดับเบิลคลิกไฟล์ `index.html` (แนะนำให้เปิดด้วย Google Chrome)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอ |
| `style.css` | หน้าตาและสี |
| `app.js` | โค้ดการทำงาน |
| `lib/xlsx.full.min.js` | ไลบรารีอ่าน/เขียน Excel ([SheetJS](https://sheetjs.com) รุ่น 0.20.3) |

## ข้อมูลเก็บที่ไหน

ข้อมูลเก็บใน browser (localStorage) ของเครื่องที่ใช้งาน **ไม่ได้อยู่ในไฟล์**
OneDrive จึงไม่ได้สำรองข้อมูลให้ — ควรกด "ส่งออก Excel" เป็นประจำ

## เพิ่ม / แก้ไข / ลบรายการ

- **เพิ่ม:** กด "+ เพิ่มรายการ" กรอกข้อมูล แล้วกด "บันทึก" (ช่องที่มี * ต้องกรอก)
- **ผู้รับผิดชอบหลายคน / หลายอีเมล:** คั่นด้วยจุลภาค เช่น `คุณ ก, คุณ ข`
- **แก้ไข:** กดปุ่ม "แก้ไข" ท้ายแถว
- **ลบ:** กดปุ่ม "ลบ" ระบบจะถามยืนยันก่อน ลบแล้วกู้คืนไม่ได้
- ข้อมูลบันทึกอัตโนมัติทันทีที่กด "บันทึก" หรือยืนยันการลบ

> คู่มือส่วนอื่นจะเพิ่มเมื่อทำแต่ละขั้นเสร็จ
